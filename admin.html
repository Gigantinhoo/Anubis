Carregando o catálogo atual…
Como publicar: salve o imóvel e clique em “Preparar arquivos para baixar”. Depois baixe os arquivos individualmente e envie todos para a raiz do repositório ANUBIS no GitHub. As fotos ficam incorporadas nos arquivos, então não precisa organizar pastas de imagens.

Editar imóvel

As mudanças ficam no navegador até você salvar os arquivos na pasta do projeto.

Cadastro local
Quebras de linha são mantidas na página individual.

Fotos do imóvel

Você pode selecionar várias fotos de uma vez. O painel reduz o tamanho das imagens automaticamente para facilitar o carregamento no celular. A primeira foto é a capa.

Galeria

Nenhuma foto cadastrada. Use “Adicionar fotos”.

Arquivos prontos para baixar

Clique em cada botão abaixo. Os arquivos serão baixados separadamente, sem ZIP. Depois envie todos para a raiz do repositório ANUBIS no GitHub. As fotos já estão dentro do HTML e do catálogo.

Catálogo de links

Clique na foto ou abra a página individual. O botão de copiar cria o link para compartilhar apenas aquele imóvel.

Privacidade: o catálogo não aparece no menu da homepage, mas não tem senha. E o arquivo imoveis.json fica no repositório público; não cadastre nele dados pessoais que não devam ser públicos. Os endereços completos existentes são preservados no arquivo, mas não aparecem nas páginas individuais.
