ANUBISGERENCIADOR DE IMÓVEIS

Gerenciar imóveis.

Edite uma casa, adicione fotos ou crie um novo imóvel. Ao publicar, o sistema gera uma página HTML individual para cada cadastro e atualiza o painel de links.

Como funciona: a homepage não mostra imóveis. Cada anúncio é publicado em uma página própria; o painel admin.html reúne os links para compartilhar. Para publicar, use um token Fine-grained do GitHub com acesso somente ao repositório Anubis e permissão Contents: Read and write. O token e a senha ficam apenas na memória desta aba. A senha também é necessária no painel da sua mãe. Criar token.

Privacidade: o catálogo de administração fica fora da homepage, mas, em hospedagem estática e repositório público, páginas e arquivos não são protegidos por senha. Esta organização impede a listagem casual no site, não é um controle de acesso.
