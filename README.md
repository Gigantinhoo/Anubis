# ANUBIS Imóveis

Site institucional responsivo para aluguel residencial em Corupá, Santa Catarina.

## Estrutura

- `index.html`: conteúdo e estrutura do site.
- `styles/style.css`: identidade visual preta e dourada, layout responsivo e estilos.
- `scripts/main.js`: catálogo demonstrativo, filtros, menu mobile e links para WhatsApp.
- `assets/images/logo-anubis-original.jpeg`: arquivo enviado do logotipo da ANUBIS (cópia original, ainda pode ser trocada por PNG otimizado).
- `assets/images/imoveis/casa-teste/`: fotos provisórias enviadas para testar a galeria.

## Como visualizar

Abra `index.html` no navegador. O site é estático e não exige instalação de dependências.

## Observações importantes

- As fotos da pasta `casa-teste` são materiais de teste, não um anúncio confirmado.
- Preço, endereço exato, disponibilidade, metragem, quartos e demais características ainda precisam ser confirmados antes de anunciar o imóvel.
- Os botões de contato usam o WhatsApp comercial informado: `+55 47 99202-4656`.
- A fonte é carregada do Google Fonts quando houver internet; o site mantém fontes alternativas caso não carregue.
- Para ativar o GitHub Pages, no repositório abra **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
